# ตารางน้ำขึ้นน้ำลง เกาะสมุย

ตารางน้ำรายวันทั้งปี 10 จุดรอบเกาะสมุย พร้อมช่วงน้ำเดินและคะแนนสำหรับตกปลา

คำนวณจากค่าฮาร์มอนิกน้ำ 27 องศา fit กับข้อมูลจริงย้อนหลัง 4 ปี (Open-Meteo Marine)

**ไม่ใช่ตารางน้ำทางการ** — เวลาใช้ได้ ความสูงเป็นค่าประมาณ (คลาดเคลื่อน ~8 ซม.)
งานที่พลาดไม่ได้ให้เทียบกับกรมอุทกศาสตร์ กองทัพเรือ
